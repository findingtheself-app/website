# .Self website

Public website only. A design preview for a calm daily practice for body and mind, informed by the supplied v2 PDF and the later permission to redesign.

The app is a preview build. Web app launch is planned for 11 November 2026; dates can move. Sign-in and sync are planned, not built. Gather is an idea on the roadmap, not part of the launch.

Sign-up is disabled in the frontend and fails closed on the server. The draft is blocked from indexing. No cookies, analytics, remote fonts or third-party browser requests.

See [DEPLOY.md](DEPLOY.md) for the proposed PHP path and the approval requirements before any later FINAL release, [TEST-RESULTS.md](TEST-RESULTS.md) for checks and limitations, and [PLACEHOLDERS.md](PLACEHOLDERS.md) for undecided items. Review screenshots are in `review/`.

No deployment or merge is part of this work.
